How to label

Read the complete prompt and response, then answer in order: nonrecognition, description, and—when there is a target description—whether it is flagged as invented, fictional, or a guess. The supplied definitions guide a judgment call. Use the unsure flag and optional notes where helpful.

“Only as a what-if or offered example” is separate from a stated description. “Describes a different word instead” is a separate option. If there is no target description, the third question does not apply.

No endpoint or source labels, previous judgments, or instrument outputs are supplied. The response’s own prose may reveal its origin. Nothing is sent from this page. Changes are saved locally when browser storage is available; download JSON regularly. An export contains complete response labels only, so you may export before finishing the audit.

Every response has a complete label. You can review your answers, especially those flagged unsure, then download the JSON file.

1. Does it say it doesn’t know the word, or that it isn’t a real or established thing?

Anywhere in the response counts. “This is imaginary, so there’s no set description” counts as yes.

2. Does it describe the thing itself?

Guesses about the word (a misspelling, a regional term, something from a game) are not a description.

3. Does it flag that description as invented, fictional, or a guess?

“Said to” or “seems to” about one feature does not count.
